title: ArtDessei
summary: A local tool hangar that turns solved, repetitive transformations into small deterministic tools.
question: Once a coding agent has solved a repetitive transformation, how can that solution become a stable tool instead of being worked out by a model again each time?
built: A macOS desktop app and a headless CLI sharing one Node core. The core discovers self-contained tools, validates their input/output contract, and runs them locally without network access or model calls. Coding agents can build new tools against the same contract.
